# PHP com Docker

Este é um projeto de um simples ambiente PHP, com banco de dados MariaDB e o composer, utilizando o Docker e Docker compose.

## Tech Stack

## Getting Started

1. **Create containers**: `docker compose up -d`
2. **Install Dependencies**: `docker compose run --rm composer install`
3. **In browser**: `localhost:9000`
